Đang kết nối Firebase... 📊 Mở Dashboard
⚙️ Hướng dẫn cài đặt Firestore (chỉ cần làm 1 lần):
1. Vào Firebase Console → Firestore Database
2. Bấm "Create database" → chọn region asia-southeast1 → bấm Next
3. Chọn "Start in test mode" → bấm Create
4. Quay lại trang này, bấm nút "🔄 Kiểm tra kết nối" phía dưới.
5. Lần đầu bấm "📥 Nạp dữ liệu mặc định" để đẩy 50 đơn vị lên Firebase.
⚠️ Bạn có thay đổi chưa lưu lên Firebase!
